# 图表抽取与嵌入

**目的：报告里必须能看到图，而不是只有"见图 3"。**

## 什么时候抽

- **L1 精读**：默认抽。全文精读、实验精读都抽；方法精读至少抽框架图/结构图。
- **L0 预览**：不抽，只读摘要与结论。
- 纯理论、无图的论文：整节跳过，写"原文无图"。

## 命令

依赖 `pymupdf`（`pip install pymupdf`）。

```bash
python scripts/extract_figures.py <paper.pdf> <paper-dir>/figures [--dpi 216]
```

输出：

```
figures/
  fig-01.png
  fig-02.png
  ...
  manifest.csv     # fig,page,caption,file,w,h,status
```

- 命名按**图号**，不按页码；同一图号重复命中时保留面积最大的一张。
- `status`：`ok` / `fallback`（按整栏区域截取）/ `check-crop`（尺寸偏小，可能裁切不全）。

## 抽取机制与边界

1. 优先取**内嵌位图**（页面里的图像块）。
2. 矢量图用 `page.cluster_drawings()` 聚类，取图注正上方、与图注横向有重叠的块。
3. 位图与矢量混排时合并两类候选，再按"离图注最近、横向重叠"选一组。
4. 仍定位不到 → 退化为"图注上方整栏"截图，标 `fallback`。
5. 扫描版 PDF 没有可抽取对象 → 只能整页渲染，标"扫描版，整页截图"。

**必须人工抽查**：`check-crop` 与 `fallback` 至少看一眼，裁切不全就手工补裁，或在报告里注明"图可能不完整"。

## 报告里怎么写

```markdown
![图1 PCN 整体结构：卷积 → OS-Block → 初级胶囊 → 并行双路由 → 融合 → 多标签输出](figures/fig-01.png)

这张图画的是整条数据流；顺着箭头从左往右看，重点在并行两支如何汇合；它说明"降参"来自并行而非堆叠。
```

规则：

- 图放在**对应段落**，不集中堆到附录。
- 每张图后面必须有一句解读：画了什么 / 怎么看 / 说明什么。
- 不对图单独编号罗列；图号与页码只进最后的证据索引。
- 图里的数字要用正文核一遍，图文矛盾直接指出（例：正文 65% vs 表 45.21%）。
- 图看不清、裁切可疑、或与原意不符 → 写明"图可能不完整/无法核对"，不装作看见了。

## 版权与仓库

- 抽出的图只放在 `papers/` 下；`papers/` 已在 `.gitignore` 里，**不进仓库、不二次发布**。
- 不要把论文原图放进 `docs/` 或 README 当示例；示例用自己生成的内容。

## 保存时的目录

```
papers/<序号-中文主题>/<年份-一作-中文短名>/
  report.docx
  figures/
    fig-01.png
    manifest.csv
```

临时 `report.md` 里的图片路径用相对路径 `figures/fig-01.png`，导出 docx 时会一起嵌入。
