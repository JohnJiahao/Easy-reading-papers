# L1 精读（组会式报告，不出 PPT）

借鉴组会汇报稿的**结构与写法**，最终产出一份 Word 报告，**不生成 pptx**。Markdown 只作转换中间稿。
目标读者是"没读过这篇的人"：外行能听懂，内行能追问。

## 执行顺序

1 基本信息 → 2 一句话结论 → 3 摘要 → 4 整体框架与全流程 → 5 关键公式 → 6 创新点 → 7 实验 → 8 结论 → 9 Claim–Evidence 速查 → 10 批判性审阅 → 11 可复现性 → 12 相关工作定位 → 13 启发/可行动项 → 14 未解决问题 → 附录证据索引

## 0 写法总则

- 术语首次出现补一句白话解释。
- `老问题 / 创新做法 / 解决了什么问题` 各写 **2–3 句（约 40–80 字）**，先结论再解释"为什么、怎么做、所以呢"，不许只写关键词。
- **创新点只写方法/思想层**：出现数据集名、精度百分比、对比模型即为违规，这些放实验。
- **摘要与结论必须完整放入**，不删减、不改写。
- 数值必须来自原文；没给就写"原文未给出"，不估算。
- **图表不单独列图号**：直接在正文里讲清"画了什么、怎么看、说明什么"；页码/图号只放进附录证据索引。
- **公式必须带符号表**：每个符号的含义、维度/索引、出现在流程哪一步，都要写。
- **公式用 LaTeX 写中间稿**：行内 `$...$`，独立公式 `$$...$$`；导出脚本会渲染成图片嵌入 Word，Word 里不显示 LaTeX 源码。
- 花括号用 `\lbrace` / `\rbrace`，不要写 `\{` `\}`——部分 Markdown 渲染器会把反斜杠吃掉。

## 1. 基本信息

- 英文论文：英文题名（原样）+ 中文译名。
- 中文论文：题名只放在报告标题，第 1 节不再重复，直接从作者写起。
- 之后接：作者与单位（一作+通讯）/ 期刊或会议 + 年份 + 卷期页 / DOI / 分区或核心收录（只写结果）/ IF（有则写）/ 阅读范围 / 目的。

分区、收录只写查到的值，不写"中文刊没有几区""以最新目录为准"这类解释。

## 2. 一句话结论

一句话说清：这篇做了什么、结论能不能站住。不超过 60 字。

## 3. 摘要

- **完整放入摘要**，**默认翻成中文**；人名、机构、专有名词保留英文原名。用户明确要英文原文或中英对照时才改。
- 翻译不删减、不改写、不省略；数字、P 值、置信区间原样保留。
- 摘要之后给要点：
  - **需要解决的问题**：2 条，一条一句
  - **解决方法**：2 条，与上面的问题**一一对应**

## 4. 整体框架与全流程

论文没有框架图或方法图 → 整节跳过，不硬编。

- 按数据流走：**输入 → 预处理 → 特征/表征 → 融合（如有）→ 主干模型 → 输出**，训练策略另起一句。
- 每步一句"做了什么 + 为什么这么做"，不要只念模块名；箭头方向与图一致。
- 结尾点**可替换点**：换信号 / 换数据规模 / 换主干 / 换任务头。
- 讲到图时直接说明"图上这一步在做哪件事"，不单独列图号；**能抽出的图要嵌进对应段落**（`![图1 画了什么](figures/fig-01.png)`），后面跟一句"怎么看、说明什么"。

## 5. 关键公式

**只列方法核心公式 2–5 个，不抄无关推导。** 每个公式给四件：

1. 原式（保留原文编号；**LaTeX 书写**）；
2. **符号表**：每个符号含义 + 维度/索引；
3. 它在流程中的位置（对应第 4 节哪一步）；
4. 为什么需要它（解决什么、去掉会怎样）。

- 公式在 PDF 里解析不出来 → 标"公式无法解析"，不要凭印象补。
- 只写"核心"，不要把损失函数的每一行中间步骤都搬上来。

## 6. 创新点（2–4 条，按重要性排序）

每条三要素：

1. **老问题**：原方法具体怎么做、卡在哪一环、导致什么后果。可用生活化类比。
2. **创新做法**：做了什么 + 一句白话机制 + 对应模块或公式编号。
3. **解决了什么问题**：落到"所以现在能……"，必须直接回应第 1 条缺陷，不写空泛的"效果更好"。

方法图不单独列"配图"项，在讲机制时顺带说清图上那块在做什么即可。

## 7. 实验

### 7.1 数据集（可选）
有数据集就写：名称、规模、类别数、工况/转速、采样率。
纯理论/纯仿真/无数据集方向 → **整节跳过**，不写"原文未提供数据集"占位。

### 7.2 实验设置（固定，即使没有数据集）
划分比例 / 关键超参 / 训练策略（分几阶段、冻哪些）/ 指标与重复次数 / 软硬件。
没给的写"原文未给出"，不用默认值补。

### 7.3 对比实验 N（括号写"验什么"）

四要素：

1. **想说明的问题**：写成疑问句 + 半句为什么值得问。
2. **实验描述**：数据、设置、逐一列基线及**关键配置差异**（如基线只能用 LoRA、本文全参）、指标与均值±std。
3. **最终说明了什么**：先结论 → 点名两头数值与差值 → 读表（哪行值得说、异常值）→ 读图（混淆矩阵错在哪两类、簇是否分开、曲线是否收敛）→ 回扣第 1 点。
4. **图表说明**：直接讲这张图/表画了什么、怎么看、结论指向哪里，不单独列图号；抽出的图就嵌在这段下面，图文矛盾要当场指出。

标题示例：`对比实验1（有效性）`、`对比实验2（跨数据集）`。

### 7.4 消融实验 N（括号写单一变量）

四要素同上，第 2 点必须写清**单一变量**：去掉哪个部件、其余条件固定为什么。

**原文没有部件级消融时**（必须处理，不能消失）：
1. 明写"**原文未提供部件级消融**"；
2. 用等价单变量实验顶上：输入表征对比 / 超参单变量 / 主干规模对比 / 阈值或窗口长度；
3. 标注"这是用 XX 替换做的单变量对比，不是原文正式消融"，数字仍取自原文。

## 8. 结论

- **完整放入结论**（语言同上），不删减、不改写。
- 之后补：作者自认局限 / 未来工作 / 摘要 vs 结论是否一致（不一致的直接点名）。
- 摘要与结论都不许用"作者提出了一种…"这类摘要式改写代替原文。

## 9. Claim–Evidence 速查

| 主张 | 证据位置（节/页/图表） | 证据类型 | 是否充分 |
|---|---|---|---|

- 只放**核心 3–6 条**，全量放附录。
- 精读报告必给此节；只有收藏卡不需要。

## 10. 批判性审阅（本 skill 的差异点，必须写）

- **内部效度**：因果还是相关？对照是否充分？有无混杂？
- **外部效度**：换域/换规模是否成立？实验覆盖够不够。
- **构念效度**：指标是否真代表目标能力。
- **统计效度**：显著性、重复次数、方差、是否后验挑阈值。
- **最强反驳**：以最善意理解构造能推翻核心结论的论证。
- **作者回避点**：该讨论却没讨论的（失败案例、负结果、成本）。
- **复现最可能失败环节**：按概率排序，写明依赖哪些未公开信息。人文社科不写这一条。

## 11. 可复现性清单

种子 / 超参 / 硬件 / 预处理 / 划分 / 阈值标定。逐项写"有 / 无 / 部分 / 未提及"。

人文社科：本节改为"材料与引文"，只写版本、底本、页码、引文可核性；不写复现、代码、数据。

## 12. 与相关工作定位

流派 — 代表工作 — 本文位置 — 与最接近工作的差异。不逐篇罗列。
无独立相关工作章节 → 从引言抽；仍无 → 标"未设独立章节"，用参考文献最接近的 2–3 篇替代。

## 13. 对我的启发 / 可行动项

- 可借鉴（能直接用的组件/思路）
- 可迁移（换到我的任务怎么改）
- 不要照搬（哪一点是坑）
- 若要做同类工作，需要补什么

## 14. 未解决问题

作者没回答、但影响结论或落地的问题，逐条列。

## 部分精读模式

| 范围 | 保留 | 裁剪 | 必做交叉检查 |
|---|---|---|---|
| method-only | 1/3/4/5/6/10/14 | 实验压缩为结论 | 关键假设是否被至少一组主实验验证 |
| exp-only | 1/3/7/8/10/11 | 方法只留输入输出与关键设定 | 实验是否在验证作者声称的贡献 |

部分精读必须在标题和 frontmatter 标 `read_scope`，不许伪装成全文精读。

## 人文社科调整

- 第 5 节写关键命题（内容 / 文本依据 / 在论证中的位置 / 去掉会怎样）。
- 第 7 节写材料与论证（版本 → 论证路径 → 反例与自我限定）。
- 标题直接写"关键命题""材料与论证""材料与引文"，不加括号说明。
- 证据类型写引文对勘 / 注疏层累 / 概念史 / 接受史，不写数据集、精度。
- 第 11 节写"材料与引文"（版本、底本、页码），不写复现、代码、数据；第 10 节不写"复现最可能失败环节"。
- 摘要与结论照旧完整放入；原文没有独立结论节时，放末节或末段全文。
- 中文人文刊写"南核（CSSCI 年份）＋北核（2023）"，不写几区。

## 按目的的详略映射

| 目的 | 加厚 | 可压缩 |
|---|---|---|
| 精读 | 2/4/5/6/7/8（标准全量） | 12/13 按需 |
| 复现 | 5/7.2/7.4/11 | 12/13 |
| 找创新点 | 6/14 + 第 10 节的最强反驳 | 7.2/11 |
| 找选题 | 10/14 + 相关工作缺口与失败案例 | 7.2/11 |
| 写综述 | 1/6/12/14 | 7.2/7.4/11 |

- **找创新点**：向内看这一篇——它的老问题、做法、解决了什么；产出是"能不能借鉴/超过"。
- **找选题**：以局限性为入口——先看作者自认的与没意识到的局限，再问"为什么没人做"，最后写成"我能做什么"；产出是"下一篇写什么"，不是"这篇哪里差"。
- 同一篇可以两个目的都做，但报告落点不同：前者加厚第 6 节，后者加厚第 10、14 节。
